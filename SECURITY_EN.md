# Security Policy

English | [简体中文](SECURITY.md)

## Supported Scope

WeChat Xposed Hook Example is a historical learning example and does not provide production security guarantees. Maintainers will try to address issues related to this repository's code and documentation, but do not promise compatibility with specific Android, WeChat, or Xposed versions.

## Reporting a Security Issue

If GitHub Private Vulnerability Reporting is enabled for this repository, use it first. Otherwise, open an Issue without vulnerability details or sensitive data and ask the maintainers for a private contact channel.

Do not publish the following in public Issues, logs, or Pull Requests:

- Exploitable vulnerability details;
- Real conversations, account details, or device identifiers;
- Access tokens, private keys, or other credentials.

Report issues in WeChat, Android, or the Xposed project itself through the corresponding upstream security channels.

## Usage Boundary

Test this project only with devices, accounts, and data that you own or are explicitly authorized to use. You are responsible for complying with applicable laws, privacy requirements, and platform rules.
